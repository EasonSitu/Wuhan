# 武汉三镇小导览

一个面向普通旅行者的武汉静态单页。它把武汉放回三镇、两江、过早、老街、轮渡和东湖里看，方便第一次来武汉的人快速判断：今天该逛汉口、武昌，还是汉阳。

## 内容

- 城市渊源：长江、汉江和三镇格局。
- 三镇速读：汉口、武昌、汉阳各看什么。
- 历史建筑：江汉关、红楼 / 省博、古琴台等代表线索。
- 风土人情：过早、普通轮渡、老汉口、东湖傍晚。
- 小吃街区：按街区放早饭、晚饭和夜宵。
- 路线组合：汉口一天、武昌一天、汉阳半日。
- 手信：周黑鸭、热干面礼盒、传统糕点方向。

## 本地预览

直接打开 `index.html` 即可。也可以在项目目录运行：

```powershell
python -m http.server 59421 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:59421/index.html
```

## 维护原则

- 手机优先，图片不能为了排版裁掉关键信息。
- 文案写事实和现场感，不写成硬种草或训人攻略。
- 餐饮尽量写街区，不做单店排行榜。
- 图片和资料尽量保留来源，方便继续校对。
- 保持静态、轻量，方便国内访问和本地打开。
